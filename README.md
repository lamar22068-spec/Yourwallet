# YOUR WALLET 
A personal expense tracking application built with Python and Tkinter, featuring expense management, categorization, budget tracking, and data persistence.
![app](<img width="1920" height="1020" alt="image" src="https://github.com/user-attachments/assets/1286ea46-0593-4809-a461-6beea33a5e02" />)

## Features
- **Add Expenses:** Easily log personal expenses with the amount, category, and automatic timestamping.
- **Display Expenses:** View all recorded expenses in a clean table showing the amount, category, and date.
- **Edit & Delete:** Update existing expense details or delete selected entries directly from the dashboard.
- **Search & Filter:** Search and filter expenses quickly by category.
- **Summary Metrics:** View total spent (in SAR) and total count of recorded expenses at a glance.

## Technologies Used
- Python 3.0
- Tkinter (Python Standard GUI Library)
